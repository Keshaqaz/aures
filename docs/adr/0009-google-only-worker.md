# Одна площадка воркера: Google Apps Script

27 октября 2026 года владелец решил убрать GitHub как площадку воркера и оставить только Google Apps Script. Тик Apps Script идёт каждые 5 минут и не пропускает слотов, а GitHub доставляет около четверти плановых запусков. Из-за этого на GitHub понадобились окно перед истечением в 8 часов, проверка с Mac и своя сессия компьютера. Поддержка двух площадок удваивала установку, починку, `upgrade`, `uninstall` и тесты. Ещё она требовала переключения площадки, самого сложного по инвариантам кода в проекте. Cloudflare как третью площадку проба отклонила (ADR-0008), поэтому выбирать больше не из чего.

**Решение.**
- Воркер живёт только в Google Apps Script в аккаунте пользователя, как описано в ADR-0007. `setup` больше не спрашивает площадку.
- Код воркера на GitHub удаляется целиком: workflow, `worker.mjs` для Actions, шифрование state, клиент GitHub API, OAuth-приложение GitHub, libsodium.
- **Переключение площадки** и **погашенный воркер** удаляются: переключаться не на что. Если появится новая площадка, переключение вернётся из истории git под неё.
- **Внеочередная проверка с Mac** и **сессия компьютера** удаляются (заменяет ADR-0005). Воркер на Apps Script сам видит исчерпание недельной квоты в пределах 5 минут, с выключенным Mac тоже.
- Существующие установки на GitHub не переносятся (у проекта один внешний пользователь). Установка, в которой нет воркера на Google, считается отсутствующей, и `setup` начинает заново. Репозиторий воркера на GitHub пользователь удаляет сам: его расписание продолжит работать, пока репозиторий существует.
- Оставшийся от проверки с Mac агент launchd убирает себя сам: скрытая команда `watch` выгружает агента и удаляет его plist. `uninstall` и `upgrade` делают то же, если агент найден, а также удаляют файлы сессии компьютера и лог проверки.

**Заменяет** ADR-0004 (воркер на GitHub) и ADR-0005 (проверка с Mac). **Уточняет** ADR-0007: площадка одна. Пауза, починка, «Применить сейчас», пробный запуск, журнал и `doPost` с секретом из Keychain остаются как в ADR-0007.

**Отвергнуто.**
- Оставить в CLI код GitHub только для `uninstall` старых установок. Это сохранило бы клиент GitHub API и OAuth-приложение ради одного пользователя, а его репозиторий удаляется вручную за минуту.
- Перенести общие правила с GitHub на Google одноразовым переключением. Общих правил всего два переключателя, и `setup` спрашивает их заново.
- Оставить проверку с Mac для Google. Она выигрывает не больше 5 минут, но стоит отдельного входа в ChatGPT и агента launchd.

**Последствия.**
- Пользователю без Google-аккаунта или без готовности пройти два экрана «непроверенное приложение» сервис недоступен. ADR-0007 отвергал замену GitHub на Apps Script как раз по этой причине. Теперь это осознанная цена.
- Окно правила перед истечением — 1 час, одно на весь сервис.
