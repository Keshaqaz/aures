# Установка и использование

[English](installation.en.md) · **Русский**

## Быстрая установка

Нужны Mac, аккаунт Google (там будет жить воркер) и платная подписка ChatGPT со сбросами.

```sh
brew install keshaqaz/tap/aures
aures setup
```

`setup` ведёт по этапам, по строке на этап; каждую страницу он открывает сам и сам продолжает, когда вы закончили.

| Этап | Что сделать |
| --- | --- |
| `[1/4] Вход в Google` | Выберите аккаунт. На странице «Приложение не проверено Google»: «Дополнительные настройки» → «Перейти на страницу "aures" (небезопасно)». Затем «Продолжить» → «Выбрать все» → «Продолжить». |
| `[2/4] Воркер в Google` | Если попросит: на открывшейся странице нажмите переключатель «API скрипта приложений Google Apps». Затем на странице «aures-worker (Unverified)»: «Review permissions» → тот же аккаунт → «Дополнительные настройки» → «Перейти на страницу "aures-worker" (небезопасно)» → «Выбрать все» → «Продолжить». |
| `[3/4] Вход в ChatGPT` | Код уже в буфере: вставьте его на открывшейся странице и войдите в аккаунт со сбросами. |
| `[4/4] Первый запуск` | Ничего: расписание и пробная проверка. |

У каждого этапа есть строка «зачем», его шаги отмечаются `✓`, а то, что нужно сделать вам, — строкой `→`. В конце — `Готово. Сбросов: N.`, и открывается главный экран aures.

<img src="assets/setup-ru.png" alt="aures setup: четыре этапа с пояснениями и галочками, «Готово» и открытие экрана">

Оба предупреждения Google о «непроверенном приложении» ожидаемы: и приложение aures, и скрипт воркера — ваши, Google их просто не проверял. Если этап ждёт дольше ~30 секунд, `setup` печатает подсказку с кнопками и ссылку на случай, если браузер не открылся. Прерванный `setup` просто запустите снова — он продолжит с того же места.

### Из исходников

Нужен Node 26:

```sh
git clone https://github.com/Keshaqaz/aures.git && cd aures
npm ci && npm run build:worker
echo "alias aures='node $PWD/src/cli/main.ts'" >> ~/.zshrc && source ~/.zshrc
```

### Язык

CLI говорит на языке системы. Сменить: `aures language ru` / `aures language en` или клавиша `l` на экране.

### Был воркер на GitHub

До версии 0.6.0 воркер можно было поставить и на GitHub Actions. Теперь он живёт только в Google Apps Script ([ADR-0009](adr/0009-google-only-worker.md)), и переносить его aures не умеет.

1. Удалите на GitHub приватный репозиторий `codex-auto-resets-worker`: Settings → Danger Zone → Delete this repository. Пока он есть, его расписание продолжает запускать воркер.
2. Если хотите, закройте доступ aures к GitHub: GitHub → Settings → Applications → Authorized OAuth Apps → Revoke.
3. Запустите `aures setup` — он поставит воркер в Google с нуля. Правила выберите заново на экране `aures`.

Агент проверки с Mac от прежней версии удаляет себя сам при первом запуске после обновления; `aures upgrade` и `aures uninstall` убирают его тоже. Вход в GitHub из Связки ключей удаляет `aures uninstall`.

## Каждый день

```sh
aures
```

<img src="assets/status-ru.png" alt="Экран aures: сбросы сверху, правила снизу, раздел о воркере">

Сверху сбросы со сроками, снизу правила, под ними — воркер: его состояние справа, следующий запуск и последнее применение.

Линия под шапкой заполняется от последнего запуска по расписанию до следующего. Заполнилась, а нового запуска нет — остаётся полной, пока воркер не запустится. На паузе вся линия пунктирная.

- `↑` `↓` — выбрать строку.
- `Enter` на сбросе — применить сейчас (`y` — подтвердить). Сброс одноразовый, отменить нельзя.
- `Enter` на правиле — включить или выключить.
- `Tab` — экран «Воркер».
- `l` — язык, `r` — обновить, `q` — выйти.

Если что-то не так, внизу появится строка с `!` и подсказкой. `aures status` печатает то же самое один раз.

## Правила

| Правило | По умолчанию | Что делает |
| --- | --- | --- |
| Перед истечением | включено | Применяет сброс в последний час до истечения. |
| Когда кончится недельный лимит | включено | Как только недельный лимит кончился, применяет сброс с ближайшим сроком. Воркер проверяет лимит каждые 5 минут, даже когда Mac выключен. |

Правила действуют на все сбросы и заработают со следующего запуска воркера. Менять — на экране `aures` или командой `aures rules`.

## Экран «Воркер»

<img src="assets/worker-ru.png" alt="Экран «Воркер»: воркер, аккаунты, действия и журнал">

`Tab` открывает и закрывает его. Здесь:

- **Воркер** — его состояние справа и ссылка на проект скрипта. На паузе скоба раздела пунктирная.
- **Аккаунты** — Google и ChatGPT; у каждого «войти заново».
- **Действия:**
  - «Проверить сейчас» — пробный запуск: воркер читает сбросы и говорит, что сделали бы правила, ничего не тратя.
  - «Починить» — заново залить текущую версию воркера и вернуть расписание. Сбросы, правила и вход не трогаются.
  - «Пауза» / «Снять с паузы» — снимает или возвращает расписание. На паузе правила не работают и сбросы сгорают в свой срок; «Применить сейчас» работает.

  Задержите курсор на действии примерно на полсекунды — под рядом откроется подпись; она остаётся открытой, пока курсор идёт по ряду, и закрывается, когда он уходит.
- **Журнал** — последние запуски воркера, новые сверху, в три столбца: когда, кто запустил (`расписание` или `вы` — проверка, вход, «Применить сейчас», действие на этом экране) и что получилось. Спокойные запуски подряд сворачиваются в одну строку, например «7 проверок — всё в порядке, применять нечего». Справа в заголовке — когда журнал прочитан и сколько отвечал воркер, или жёлтое «воркер не ответил». Пока экран открыт, журнал опрашивается каждые 30 секунд. `↓` с действий переводит в журнал; его скоба — полоса прокрутки.

Пока экран читает воркер, по скобе журнала идёт бегунок: быстрый ответ — быстрый пролёт, медленный — бегунок ползёт, жёлтая остановка — ответа нет. Пока идёт действие, скоба его раздела заполняется — у входа и «Применить сейчас», чьё время неизвестно, по ней вместо этого бежит бегунок, — а в конце вспыхивает зелёным или жёлтым, если нужно взглянуть. С `AURES_MOTION=off` или заданным `NO_COLOR` ничего не движется.

## Если что-то сломалось

Если воркер упал, Google присылает письмо о сбое триггера. Запустите `aures status` — он скажет причину и что делать.

| Сообщение | Что сделать |
| --- | --- |
| Воркер потерял вход в ChatGPT | `aures login` |
| Установка не завершена; воркер на Google не отвечает | `aures setup` |
| У воркера нет расписания | «Починить» на экране «Воркер» |
| Google не запускал воркер по расписанию N ч | Проверьте выполнения скрипта по ссылке из сообщения |
| Скрипту выданы не все доступы | `aures setup` откроет согласие снова: отметьте обе галочки |
| Это другой аккаунт ChatGPT | Войдите в аккаунт, для которого ставили воркер, или переустановите: `uninstall`, затем `setup` |

## Обновление

```sh
brew upgrade aures
aures upgrade
```

`aures upgrade` обновляет сам воркер; правила, журнал и вход в ChatGPT сохраняются. Он может снова попросить вход в Google, если тот отозван, — те же кнопки, что при установке. Из исходников: `git pull && npm ci && npm run build:worker`, затем `aures upgrade`.

С версии до 0.3.0 (`codex-auto-resets`) обновитесь один раз по полному имени: `brew update && brew upgrade keshaqaz/tap/aures && aures upgrade`.

## Удаление

```sh
aures uninstall
brew uninstall aures
```

`uninstall` спросит подтверждение, остановит воркер, отзовёт его вход в ChatGPT и уберёт всё, что относится к aures на этом Mac. Вход aures в Google отзывается для всего аккаунта, так что на другом Mac следующий `upgrade` попросит войти заново. Проект скрипта CLI удалить не может — в конце будет ссылка: перенесите `aures-worker` в корзину на script.google.com (или оставьте: он больше ничего не делает).

## Что где хранится

| Где | Что |
| --- | --- |
| Связка ключей Mac (служба `codex-auto-resets`) | вход в Google и секрет воркера |
| Проект `aures-worker` (Google) | воркер, расписание, правила, журнал и вход воркера в ChatGPT (в Script Properties) |
| `~/Library/Application Support/codex-auto-resets/` | адрес воркера, аккаунты, выбор языка |

Web app воркера отвечает только на запросы с секретом из Связки ключей вашего Mac и не отдаёт токены. Подробнее о безопасности — [ADR-0007](adr/0007-two-worker-platforms.md).

## Сколько это стоит

Ничего: 5–10 минут триггеров в сутки из 90 бесплатных. Если у вас есть другие скрипты Apps Script, учитывайте общий расход.
